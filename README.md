# genz-in-action
Cross-platform social-impact community application built with React Native, Expo, TypeScript and Supabase.

| Folder | What it is |
|---|---|
| `mobile/` | The Expo app. See `mobile/README.md` to run it. |
| `supabase/` | Database changes as SQL files run in the Supabase SQL Editor. **Read `supabase/README.md` for the run order.** |
| `docs/` | Spec (`GenZ-in-Action-Spec-v2.0.docx`), `CURRENT_STATE.md`, `decisions.md`, acceptance tests. |
| `reference/figma-prototype/`, `design-reference/` | Figma Make web prototypes: visual reference only, not shipped. |
